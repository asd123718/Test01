# 《群星未央：黑暗森林联合体》

二次创作长篇。时间锚点为《三体》危机纪元早期、面壁计划刚启动；穿越势力来自《无尽的拉格朗日》巅峰期、《明日方舟：终末地》帝江号，以及漫威《终局之战》浩克响指完成后。

主题不是“各作品角色暴打三体”，而是：多套科技树突然合作时，发展是相加还是指数爆炸。联合体最终被写成去中心化的文明网络。

## 成品

- 正文：`output/群星未央：黑暗森林联合体.txt`（约 20 万汉字，50 章 / 七卷）
- 设定检索总录：`research/世界观设定检索总录.txt` 实际为 `research/世界观设定检索总录.md`
- 质检：`output/质检报告.txt`

## 重新生成

```bash
cd novel/generator
python3 main.py
```

生成器从五十章独立剧情核（事件、台词、文献）扩写，人物声口与专有名词来自检索库。不要把输出当成原著逐字摘录。

## 卷目

1. 裂隙：面壁、时空异常、帝国/财团/帝江号/复仇者抵达  
2. 初遇：联合国接触、工业伦理、彼得成为学徒  
3. 磨合：吨位法、物流、L4 星门、AIC、纳米与智能核心、未央草案  
4. 暗流：ETO、三位面壁者禁区、水滴、黑暗森林  
5. 入盟：智子开口、存续委员会、SIM 拦截弹、三体自治、工业种子  
6. 网络：比邻星、花园星备份、融合舰、撤离演习、小宇宙、远方监听  
7. 田园：田园工程、光粒与网络、格言、终章  

格言：文明不应因被看见而获罪，宇宙也不应因文明的恐惧而死去。

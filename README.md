# 《群星未央：黑暗森林联合体》

二次创作长篇生成器。时间锚点为《三体》危机纪元早期、面壁计划刚启动；穿越势力来自《无尽的拉格朗日》巅峰期、《明日方舟：终末地》帝江号，以及漫威《终局之战》浩克响指完成后。

**本卷写到三体发现并点名其余势力为止。** 不写联合体成立，不写田园终局。主题仍是科技树突然相遇时，发展是相加还是指数爆炸——爆炸被写成可能性，而不是已经举行的庆典。

格言（草稿）：文明不应因被看见而获罪，宇宙也不应因文明的恐惧而死去。

## 重新生成

仓库根目录：

```bash
python -m generator.main
# 或
python generate.py
```

需要 Python 3.10+，无第三方依赖。生成器从五十章独立剧情核扩写；人物声口来自 `generator/voices.py`，专有名词来自 `generator/lore.py`。不要把输出当成原著逐字摘录。

字数是统计指标，不是硬门槛。质检会拒绝“值班补记”式注水和每章重复的套餐模板。

## 卷目

1. 裂隙 — 面壁、时空异常、帝国 / 财团 / 帝江号 / 复仇者抵达  
2. 初遇 — 联合国接触、工业伦理、彼得成为学徒  
3. 磨合 — 吨位法、物流、L4 星门、AIC、纳米与智能核心、未央草案  
4. 暗流 — ETO、三位面壁者禁区、水滴、黑暗森林  
5. 分类 — 智子无法把来客揉成一种文明，逐项点名  
6. 点名 — 猎场模型失效，开口请求对话；终章停在发现  

## 正文片段

罗辑被点到名时，自己正在看翻译器电量：

> 「我是不是走错门了。这里看起来不像天文学年会。」罗辑说，轻得像在抱怨旅馆空调，重的部分藏在反问里。

智子完成分类时：

> 「其余势力已被点名。点名不是联盟。」智子说。没有停顿，也没有为人类准备的语气。

## 工程结构

```
generator/     剧情核、声口、意象、扩写引擎、质检
research/      跨作品设定检索总录
output/        正文与质检报告
tests/         单元测试（含全文禁注水抽查）
```

世界观事实 → 章节剧情核 → 声口与一次性意象 → 正文。附加块（手记 / 人间 / 异议 / 短波）按章选择出现，不再五十章全套餐。

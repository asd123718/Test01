# 无尽寒冬 | Endless Winter

末日题材 2D 俯视角生存射击游戏，灵感来自电影《后天》与《2012》——假设灾难**永远不会结束**。

## 游戏特色

- **持续灾难系统**：暴风雪、连环地震、无尽洪涝、火山灰幕、极寒冻结、陨石雨、剧毒迷雾、太阳风暴轮番降临
- **80+ 枪械型号**：手枪、冲锋枪、步枪、霰弹枪、狙击枪、机枪及特殊武器
- **大量 NPC**：平民、医生、士兵、科学家、商人、难民等 14 种角色，各有独立对话
- **感染者**：蹒跚者、狂奔者、蛮力者、喷吐者四种变异人类
- **感染动物**：感染犬、狼、鼠群、鸟群、熊
- **程序生成地图**：废墟、雪地、森林、冰面、洪水区域
- **无需外部美术资源**：所有精灵程序化绘制

## 运行要求

- Python 3.10+
- Windows / macOS / Linux PC

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标 | 瞄准与射击 |
| R | 换弹 |
| 1-9 | 切换武器 |
| Tab | 武器库轮盘 |
| E | 与附近 NPC 对话 |
| Q | 随机获取新武器 |
| M | 开关小地图 |
| H | 显示/隐藏帮助 |
| ESC | 暂停 |

## 项目结构

```
main.py              # 游戏入口
game/
  engine.py          # 主游戏循环
  entities.py        # 玩家、NPC、感染者、动物
  weapons.py         # 70+ 枪械数据
  disasters.py       # 灾难系统
  world.py           # 地图生成
  sprites.py         # 程序化精灵
  ui.py              # 界面与 HUD
  settings.py        # 配置常量
requirements.txt
```

## 剧情背景

2012 年地壳剧变后，全球气候彻底崩溃。极寒风暴席卷北半球，海平面持续上升，火山灰遮蔽天空——灾难从未停止。幸存者在废墟中挣扎，感染者与变异动物在永冬中游荡。你是最后的幸存者之一，在无尽的寒冬中寻找希望。

## 技术说明

- 引擎：**Pygame 2.x**（纯 Python 2D，无物理引擎）
- 碰撞：简单圆形距离检测
- 渲染：俯视角 2D，tile 地图 + 精灵
